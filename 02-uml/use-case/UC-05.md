# UC-05 — Выолнить заявку

## Оснвоной актор - Техничсекий специалист

## Цель - Выполнить назначенные технические работы и передать отчёт о результатах

__Предварительные условия__

* Технический специалист авторизован в ИС
* На специалиста назначена заявка
* Специалист имеет возможность просматривать назначенные заявки и прикреплять отчёты

__Оснвной сценарий__

1. Технический специалист открывает список назначенных ему заявок
2. Специалист выбирает заявку для выполнения
3. Специалист выполняет необходимые технические работы
4. Специалист подготавливает отчёт о выполненных работах
5. Специалист прикрепляет отчёт к заявке в ИС
6. ИС сохраняет отчёт и проверяет наличие необходимых данных для завершения заявки
7. ИС устанавливает статус «Выполнена»
8. ИС уведомляет заявителя об изменении статуса

__Альтернативный сценарий__

1. Специалист пытается завершить работу по заявке без прикреплённого отчёта
2. ИС не переводит заявку в статус «Выполнена»
3. ИС сообщает специалисту о необходимости прикрепить отчёт
4. Специалист прикрепляет отчёт, после чего ИС продолжает выполнение основного сценария с шага 6

## Примечание

Контроль сроков и уведомление о приближении дедлайна выполняются в рамках UC-09 «Проверить сроки активных заявок». Эти действия не относятся к альтернативному сценарию UC-05

## Результат

Технические работы выполнены, отчёт сохранён в ИС, заявке присвоен статус «Выполнена», заявитель уведомлён
