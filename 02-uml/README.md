# UML-моделирование

В данном разделе предоставленны UML диаграммы ИС обработки IT-заявок. Диаграммы описывают отношения пользователя с системой, процесс обработки заявки и автоматический контроль сроков выполнения. 

## Структура раздела

1. __Use Case Diagram - диаграмма вариантов использования __

[Изображение диаграммы](use-case/use-case.png)

[Исходник](use-case/use-case.drawio)

Диаграмма отражает основных участинков системы и доступные варианты ее использования, такие как: Создание заявки, проверки статуса, просмотра назначеных заявок, прикрепление отчёта, просмотр отчета и автоматический контроль сроков

Подробное описание основных сценариев:

* [UC - 01 - Создание заявки](use-case/UC-01.md)
* [UC - 05 - Выполнение заявки](use-case/UC-05.md)

[Изображение диаграммы](activity/activity_applications.png)

[Исходник](activity/activity_applications.drawio)
