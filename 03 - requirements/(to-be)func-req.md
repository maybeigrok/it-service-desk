# Функциональные требования TO-BE

## Обработка IT-заявки

| ID | Функциональное требование |
|---|---|
| FR-01 | Система должна предоставить заявителю возможность создать заявку |
| FR-02 | ИС регистрирует заявку в базе данных |
| FR-03 | ИС проверяет заполнены ли все обязательные данные |
| FR-04 | Если обязательные данные не заполнены, ИС отправляет запрос заявителю |
| FR-05 | Заявитель дополняет данные и сохраняет. После этого ИС повтторно проверяет обязательные данные |
| FR-06 | ИС определяет и назначает ответственного специалиста в соответсвии с BR-01 |
| FR-07 | ИС уведомляет сотрудника о назначении на заявку |
| FR-08 | Сотрудник выполняет работу |
| FR-09 | Сотрудник заполняет отчёт |
| FR-10 | Сотрудник прикрепляет отчет в ИС |
| FR-11 | ИС измсеняет статус заявки на "Выполнена" полсле заверешения работы и прикрепелния отчёта |
| FR-12 | ИС уведомляет заявителя о изменении статуса заявки на "Выполнена" |

## Автоматический контроль сроков

| ID | Функциональное требование |
|---|---|
| FR-13 | ИС ежедневно в 9:00 получает из базы данных все активные заявки |
| FR-14 | ИС проверяет каждую активную заявку на истчение срока |
| FR-15 | Если есть просроченые заявки, ИС фиксирует их и изменяет статус на "Просрочена"|
| FR-16 | ИС проверяет не прочроенные заявки, на то, осталось ли им до итсчение срока 24 часа |
| FR-17 | Если времени меньше 24 часов, ИС уведомляет ответсвенного специалиста о приближающихся сроках |
| FR-18 | После проверки всех активных заявок ИС определяет, были ли зафиксированы просроченные заявки |
| FR-19 | Если были зафиксированы просроченные заявки, ИС формирует отчёт о просроченных заявках |
| FR-20 | ИС направляет сформированный отчёт руководителю |
