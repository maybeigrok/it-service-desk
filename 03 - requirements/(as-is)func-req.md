## Функциональные требования AS-IS

# Обработка IT-Заявки

| ID | Функциональное требование |
|---|---|
| FR-01 | Система должна предоставить заявителю возможность создания заявки |
| FR-02 | Рукводоитель должен получить заявку |
| FR-03 | Рукводоитель должен заполнить данные в Excel таблицу |
| FR-04 | Рукводоитель должен проверить не отсутствуют ли обязательные данные |
| FR-05 | Если все обязательные данные заполнены, то рукводоитель вручную назначает ответственного специалиста |
| FR-06 | Если обязательные данные не заполнены, рукводитель доллжен свзяаться с заявителем, о предоставление данных |
| FR-07 | Рукводоитель должен повторно проверить данные, после дополнения данных заявителем |
| FR-08 | Специалист должен выполнить работу |
| FR-09 | Специалист должен заполнить отчет о проделанной работе |
| FR-10 | Специалист должен сообщить руководителю об окончании работ и предоставить отчёт |
| FR-11 | Рукводоитель должен закрыть в Excel таблице заявку |
| FR-12 | Рукводоитель должен сообщить заявителю о завершении его заявки |

# Контроль сроков

| ID | Функциональное требование |
|---|---|
| FR-13 | Рукводоитель должен каждый рабюочий день проверять если в Excel таблице активные заявки |
| FR-14 | Если есть активные заявки рукводоитель должен проверять у каждой срок на актуальность |
| FR-15 | Если нет активных заявок, контроль скроков завершен |
| FR-16 | Если у заявки истек срок, рукводоитель должен изменить статус заявки в таблице "Просчрочено" и сформировать отчёт о просрчоенной заявке|
| FR-17 | Рукводоитель должен сообщить сотруднику о истечении срока заявки и может переходить к проверке следующей заявки |
| FR-18 | Если срок у заявки не истек, рукводитель должен проверить осталось ли до истченеия срока меньше суток |
| FR-19 | Если до истечения срока осталось меньше суток, рукводоитель должен уведомить сотрудника об этом |
| FR-20 | Если до истечения срока осталось больше суток, рукводоитель может переходить к проверке следующей заявки |
