## Описание задачи

В рамках проекта рассматривается процесс обработки IT-заявок в организации, где обращения регистрируются, распределяются и контролируются руководителем в ручную.

Проектируемая информационная система должна обеспечить автоматическую регистрацию и проверку заявок, автоматическое распределение заявок между специалистами с учтём их загруженности, прозрачность статусов работы и контроль сроков исполнения

## Проблемы текущего процесса

В исходной модели присутствуют следующие проблемы:

- Регистрация, проверка и учёт информации выполняется вручную
- Назначение ответственного специалиста зависит от руководителя
- Контроль сроков производиться в ручную и не систематизирован
- У заявителя нет возможности быстро и самостоятельно узнать статус обращения
- Подготовка отчётности выполняется вручную, занимает время руководителя

## Целевой процесс

Предполагается, что информационная система позволит:

- Регистрировать заявки и проверять обязательные поля
- Запрашивать недостающие данные у заявителя
- Назначать технического специалиста с учтём бизнес правила
- Заявителю и руководителю легко отслеживать статус обращения
- Отправляет и принимать отчёт о выполненной работе.
- Ежедневно проверять сроки активных обращений
- Уведомлять ответственных сотрудников и автоматически формировать отчёт о просрочках 

## Функциональность системы

| Функциональный блок | Назначение |
|---|---|
| Регистрация заявок | Создание заявки и проверка обязательных данных |
| Назначение специалистов | Распределение заявок по бизнес-правилам |
| Обработка заявок | Выполнение работ и прикрепление отчёта | 
| Контроль сроков | Выявление просрочек и приближающихся дедлайнов |
| Отчётность | Формирование отчёта по просроченным заявкам |

## Структура проекта

- `01-bpmn/` - моделирование процессов AS-IS
- `02-uml/` - диаграммы вариантов использования и деятельности, спецификации Use Case
- `03-requirements/` - функциональные требования и бизнес-правила
- `04-database/` - проектирование базы данных и SQL-запросы (раздел будет дополняться по мере разработки)
- `05-api/` - описание интерфейсов взаимодействия с системой (раздел будет дополняться по мере разработки)

## Используемые технологии и нотации

- **BPMN 2.0** - моделирование бизнес-процессов
- **UML** - описание поведения системы и взаимодействия с пользователями
- **SQL** - планируемое проектирование базы данных и работа с данными
- **REST API и JSON** - планируемое описание интерфейсов обмена данными
- **Git и GitHub** - хранение исходников, документации и истории изменений
